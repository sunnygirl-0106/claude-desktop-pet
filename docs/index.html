想装到自己电脑上？(macOS)

# 需要 Node.js
git clone https://github.com/sunnygirl-0106/claude-desktop-pet.git
cd claude-desktop-pet
npm install
npm start   # 宠物就出现在桌面右下角啦

再按 README 把 hook 接到 ~/.claude/settings.json，它就能实时读出 Claude Code 在干嘛 💕
